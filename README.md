# ITICAS — Ibadan Traffic Intelligence and Congestion Analysis System

Stage 01 establishes the working application foundation.

## Included
- FastAPI backend
- Attractive responsive dashboard
- Health/status API
- SQLite-ready application structure
- Windows one-click install, tests, and launch scripts
- Basic automated tests
- Modular folders for traffic acquisition, analysis, ML, reports, and exports

## Run on Windows
1. Extract the ZIP to:
   `%USERPROFILE%\iticas`
2. Run:
   `INSTALL.cmd`
3. Run:
   `RUN_TESTS.cmd`
4. Run:
   `RUN_APP.cmd`
5. Open:
   `http://127.0.0.1:8765`

Stage 02 will add the persistent database schema and geospatial/location catalogue.
