# ITICAS Stage 08 — Provider Readiness + Weather Reference Intelligence

Stage 08 adds a provider diagnostics centre and independent weather context to nationwide traffic evaluation.

- TomTom Search and Traffic authorization/readiness checks without exposing the API key.
- DNS readiness for TomTom, Open-Meteo and OSM tiles.
- Open-Meteo current weather context for arbitrary Nigerian coordinates.
- ERA5-Land historical reanalysis exposed as a standardized environmental reference source.
- Traffic validation remains explicitly provider-reference based until an independent Nigeria-wide traffic benchmark is configured.
- Nationwide search remains available for any road, junction, town, city, LGA, state, landmark or coordinates in Nigeria.
- Web/Windows shared-core and security architecture are preserved.
