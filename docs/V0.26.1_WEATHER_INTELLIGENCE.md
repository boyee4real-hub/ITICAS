# ITICAS v0.26.1 — Weather Intelligence Completion

Patch release preserving Stage 26 scientific prediction architecture while exposing weather as a first-class nationwide user module.

## Added
- Standalone `/weather` Weather Intelligence & Forecast Centre.
- Search any Nigerian road, junction, town, city, LGA, state, landmark or coordinates using the existing national search service.
- Select existing monitored locations directly.
- Current conditions and traffic-relevant weather metrics.
- 3/5/7-day forecast with first 24-hour detailed table.
- Precipitation probability, rain/precipitation, humidity, apparent temperature, cloud cover, pressure, visibility, wind and gusts.
- WMO condition labels and transparent weather hazard advisories.
- Recent 30-day weather history for research context.
- Forecast CSV download.
- Open-Meteo provenance.

## Scientific rule retained
Weather does not automatically change traffic predictions. A weather effect is applied to traffic forecasts only when the road-specific Stage 26 empirical calibration/holdout gate validates it.
