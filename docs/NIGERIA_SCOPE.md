# ITICAS Scope Amendment — Nigeria-wide Coverage

ITICAS is no longer an Ibadan-only application.

Current scope:
- any road, junction, corridor or monitoring point in Nigeria;
- city-aware and state-aware monitoring records;
- Nigeria-wide geocoding queries;
- nationwide traffic-provider architecture in later stages;
- Ibadan retained only as the initial demonstration catalogue.

Application name:
Nigeria Traffic Intelligence and Congestion Analysis System (ITICAS)

Developer credit:
Dr. Oyeyode A.O.

The application must not hard-code future traffic collection, analysis, prediction or reporting logic to Ibadan.
